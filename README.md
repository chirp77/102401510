# 校园失物招领 · Campus Lost & Found

一个**纯前端**的校园失物招领网站：发布寻物启事 / 失物招领、集中浏览、关键词搜索、查看详情并联系发布者、在物品归还后由发布者更新状态。

基于第一次结对作业的 HTML 原型实现。**零依赖、零构建、零服务器**——下载全部文件后用 Chrome 打开 `index.html` 即能看到预期效果。

## 二、运行与使用说明

### 环境要求

| 项 | 要求 |
| --- | --- |
| 浏览器 | **Google Chrome**（开发与测试统一使用，建议最新版） |
| 其他环境 | 无。不需要 Node.js、npm、服务器、数据库、任何第三方库 |

### 运行主程序

1. 下载 / 克隆本仓库全部文件；
2. 双击 `index.html`，或右键 → 打开方式 → Google Chrome；
3. 首次打开会自动载入 13 条演示数据（可正常浏览、搜索、发布、改状态）。

### 运行单元测试

1. 用 Chrome 打开 `test/index.html`；
2. 页面自动运行全部 **91 个测试用例**，并显示通过率、每套用例明细；
3. 失败用例会红底列出期望值与实际值，点击"刷新页面"可重跑。

### 数据说明

- 所有数据保存在浏览器 `localStorage` 中（键：`lost-found/items/v1`），**无需联网**；
- 若 localStorage 不可用（隐私模式、配额写满等），自动降级为内存存储，页面不会白屏；
- 想恢复初始演示数据：F12 打开开发者工具 → Console 执行
  `localStorage.removeItem('lost-found/items/v1')` → 刷新页面。

## 三、功能清单

### 核心功能（作业要求）

| 功能 | 入口 | 说明 |
| --- | --- | --- |
| 发布寻物 / 招领信息 | 顶栏「发布信息」 | 名称、分类、区域、地点、时间、描述、联系方式、昵称（可传图 3 张）；必填项与格式错误逐项标红 |
| 集中浏览 | 首页 | 卡片流展示全部信息，寻物 / 招领、寻找中 / 已归还标签一目了然 |
| 关键词搜索 | 顶栏搜索框 | 匹配名称、分类、区域、地点、描述、发布者；空格分隔多关键词（需全部命中）；命中词高亮 |
| 查看详情 + 联系方式 | 点击卡片 | 详情页含时间、地点、描述、发布者；「联系 TA」弹出联系方式，「复制联系方式」一键复制 |
| 更新信息状态 | 我的发布 / 卡片「改状态」 | 物品找回或归还后由发布者标记「已找到 / 已归还」，支持撤销改回 |

### 附加特点（非作业要求）

| 特点 | 说明 |
| --- | --- |
| 四维筛选 | 侧边栏按 信息类型 / 物品分类 / 所在区域 / 处理状态 筛选，每项实时显示数量，可一键重置 |
| 一键复制联系方式 | 详情页与弹层内均可复制；自动识别手机号 / 微信 / QQ / 邮箱类型 |
| 照片上传与压缩 | 最多 3 张，Canvas 压到最长边 720px 再存本地，避免撑爆 localStorage 配额 |
| 「我的发布」看板 | 统计我发布的 / 寻找中 / 已归还 / 找回率，支持编辑、改状态、删除、一键清空 |
| 安全防护 | 所有用户输入经 HTML 转义防 XSS；详情页附当面交接安全提示 |
| 容错体验 | 搜索无结果、发布信息不完整、非法联系方式等均有明确提示，不只有"顺利路线" |

## 四、操作指南

**主流程：发布 → 浏览或搜索 → 查看详情 → 联系发布者 → 更新状态**

1. **发布**：点右上角「发布信息」→ 选择"我丢了东西 / 我捡到东西"（表单元文案自动切换）→ 填写必填项（名称、区域、分类、地点、联系方式）→「发 布」→ 弹出成功提示，可跳详情。
2. **浏览**：首页按"未归还优先、发布时间倒序"展示；左侧可筛选类型 / 分类 / 区域 / 状态，顶部下拉切换新旧排序。
3. **搜索**：顶栏输入关键词（如 `校园卡`、`图书馆 钥匙`），自动跳转首页过滤并高亮命中词；点搜索框右侧 ✕ 或筛选标签上的 ✕ 清除条件。
4. **详情与联系**：点卡片进入详情 →「联系 TA」查看联系方式 →「复制联系方式」→ 线下当面交接。
5. **更新状态**：物品找回 / 归还后，发布者在「我的发布」（或自己卡片上的「改状态」）中标记「已找到 / 已归还」——列表、详情、筛选计数同步更新，减少后续重复询问。
6. **编辑 / 删除**：仅发布者本人可见"编辑 / 删除"按钮（以本机数据标记"我"的信息；演示数据中以发布者「我」的两条为例）。

## 六、技术要点（供测试人员了解）

```
index.html ──(加载)──> app.js ──(调用)──> core.js ──(读写)──> localStorage
                          │                 │
    hash 路由 (#/list、#/item/:id、#/publish、#/mine) 驱动视图切换
    事件统一走 document 事件委托，按 data-act 分发
```

- 数据模型：每条信息含 `id / type(寻物|招领) / category / title / area / place / desc / contact / contactType / occurredAt / images / publisher / status(寻找中|已归还) / createdAt / updatedAt`；
- 状态流转：`changeStatus` 采用不可变更新（返回新数组），原数据不被原地修改；
- 渲染安全：所有用户输入拼接进 HTML 前一律经过 `escapeHtml` 转义。
